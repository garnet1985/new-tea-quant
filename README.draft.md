## NTQ 是什么？

**New Tea Quant** 新茶量化（NTQ）是面向个人开发者的中国 A 股量化研究与机会扫描框架。（**New Tea** 来自作者的宠物蓝猫「新茶」，也是应用内 AI 助理的名字。）通过 AI 赋能，提供专业的回测、微调、对比功能来优化您的策略，并可以使用策略扫描市面上的机会。

## 一键安装

新茶量化的安装非常简单，进入**项目的根目录**，然后只需要一个指令：

```bash
python3 launcher.py
```

接下来只要按照 UI 提示安装就可以了（最简单的方式就是全部都选默认）。

**请注意**

- 有的时候您本地的 python 命令可能不同（`python` vs `python3`），路径也可能不同（`launcher.py` vs `./launcher.py`）。
- NTQ 0.5.x 最低运行 Python 版本是 3.9，从 0.6.0 起将变成 3.11（3.9 官方已经不再维护了）。但请注意建议您使用 3.11–3.13 版本，因为 NTQ 执行依赖编译后文件，最新 Python 的一些依赖编译后文件可能还没有上市，这是依赖方的问题，NTQ 无法解决。您可以通过 `python3 --version` 查看您本地的 Python 版本。

## 新茶量化能做什么？

**注意**：下边所有列举的功能都可以直接通过新茶量化的 AI 助手完成，也可以通过您本地的智能体（比如 Workbuddy、Harness、TreaWorker、豆包等）直接使用。

### 制定策略

如果您的脑海里有一个投资策略的想法，您可以通过代码或者 AI 智能体在新茶量化里制定，并且通过修改参数 / 归因 / 滚动测试来验证您的策略是否有盈利能力。

当策略制定完成，您可以使用新茶量化在历史行情中进行回测。

新茶量化的回测一共有 4 个步骤构成：

- **机会盘点**：通过您的策略在历史数据中找到所有的机会，然后盘点：机会多还是少、集中还是分散。这一步主要用来验证策略找到机会的能力和特性。
- **价格回测**：通过对上一步找到的机会进行过滤筛选，排除可能重复的机会，然后看这些机会最终能够完成您的投资目标，从而检验当前策略是不是能够做到基本盈利。
- **投资模拟**：给您一个虚拟仓位，由您制定一个投资策略，然后模拟您的资金管理策略是不是能抓住上一步的盈利空间从而真的获取收益，这一步是最接近实盘的模拟。
- **决策模拟**：和上一步做的事情完全一样，不同的是，上一步是自动决定怎么管理资金来投资，而这一步变成了您亲自经历投资过程，做出投谁、投多少的决定。这一步是真正验证策略是不是适合您的关键一步，也是很多回测 app 忽略了的「临场抗压」是如何影响「投资判断」的步骤。

另外还有：

- **滚动对照**：您可以直接调整一组参数或者不同时间段，滚动对比验证您的想法和策略。
- **归因**：您还可以对参数进行归因，看看参数变化如何影响您的结果的方向和敏感度（需要安装机器学习插件）。
- **策略版本**：因为您的参数设置变更而引起的不同结果，系统会自动创建新的版本同时保留老版本（但有上限），您可以直接对比不同版本产生的结果或者在不同版本间来回切换。

当然，上边这些如果您不擅长代码，完全可以托付给新茶量化的 AI 助手，也可以使用您自己的智能体让他来帮您执行，您只需要发号施令就可以了。

### 策略选股

您辛辛苦苦调试好的策略，总要有用武之地吧。在这里，您可以使用调试好的策略去市场上直接扫描哪些股票满足您当前策略的投资条件，通过扫描后处理，您可以直接接入自动交易、过滤、通知、机器学习等等后续处理。当然如果您没有可用的后续处理，新茶量化的用户界面上仍然能看到扫描结果。

**注意**

- 目前新茶量化只提供演示数据，如果您要拿到最新数据，需要自行接入数据源。
- 扫描后处理需要您自己配置或者接入，新茶量化默认给每个会员发 30 封通知邮件（通知扫描结果）的演示额度。

### 特征标签

这个您也可以简单地理解成量化里很火的概念「因子」。简单来说，新茶量化可以通过代码把一些特征抽象出来，绑定在一些实体上。举个例子，如果平常您判断一个公司「大」「小」市值的标准是超过 50 亿市值就是「大」，否则就是「小」，那么您就可以抽象这个算法然后提前给所有股票算好。这样这个规则可以广泛用于您的任何策略，不需要策略里现计算从而大大提高效率。当然，积累特征值本质上也就是积累您自己的「因子」。

### 数据源接入（外部）

新茶量化提供了一套方便接入外部数据源的框架。可以使用多线程并且自动遵守您定义的「限流」规则来接收外部数据防止被禁，同时支持配置化接入，支持错误重试、断点续传等等。

**注意**

- 只要您使用新茶量化，无论是否注册会员，您都有 300 个股票 3 年的历史数据用来测试。
- 如果您在官网注册会员，演示数据可以从 300 股增加到全市场（约 5800+ 只股票），但是数据时间段不变。
- 您如果有自己的数据源，可以直接接入，当然您也可以直接接入类似 AkShare 这类免费数据源。

### 数据契约

这是新茶量化「配置驱动」的主体之一。在新茶量化中，任何一个数据都会通过「数据契约」来标准化数据结构和读取方式，从而实现您需要数据只要「声明」一下就能自动注入的能力。

### 走势关联

您是不是经常想知道 A 股票和 B 股票是不是反着走，一个涨一个就跌，或者是不是 A 股票总是先涨，然后过几天 B 股票再跟着涨？又或者是不是想知道央行加息或者降息如何影响整个股票市场的总投入量？那您就可以把他们单独拉出来，通过走势关联清晰地看到他们的趋势以及走势相关性和延迟性。

### 扫描后机会处理

这里就是之前策略机会扫描里提到的当策略扫描到机会后该如何处理这些机会的模块。您可以创建任意多个机会处理方案，每个方案都能从小的可执行单元（adapter）里选取一些执行能力放进来，然后当扫描结束以后，就能自动对扫出的机会执行您编辑好的后续方案。

**注意**

- 小的执行单元新茶量化只提供 2 个可用的：presenter —— 在显示机会的时候去读取回测结果，从而让你在处理机会前知道当前股票在当前策略里的回测表现；ntq email service —— 通过 NTQ 官网发送通知邮件，这个每个注册会员只有 30 封的演示额度，一次性，不超时，用完为止。
- 其他小执行单元只是演示作用，需要您写代码或者获取第三方认证后才能使用。

### 设置

个人偏好与系统配置（含会员凭证、演示数据截断日、缓存清理等）。官网注册会员可使用部分 AI / 邮件额度（以官网与应用内说明为准）。

### 命令行（`cli.py`）

所有您在 UI 界面能看到的功能，其实最先都是在命令行里先实现的。您只要记住两个命令：

```bash
python cli.py    # 这个命令是用户使用的帮助命令，您可以在帮助里了解所有命令行的使用方式和参数
python devcli.py # 这个命令是给开发者使用的，会直接输出一些快捷开发指令，方便开发使用
```

您可以通过帮助说明脱离用户界面而直接使用或者二次开发新茶量化。
