# AI 通道 — 用户指南

**模块：** `infra.ai` · **版本：** `0.1.0`

**最低支持核心版本：** `>=0.6.0`

AI 通道——和各家 AI 模型供应商打交道，发现供应商、存 API Key、发请求。  
相关：[README.md](../README.md) · [API.md](../API.md) · [ARCHITECTURE.md](./ARCHITECTURE.md)

---

## 功能总览

- 列出你装好的 AI 供应商（设置页里能看到几家，就是它扫出来的）
- 保管你在设置页填的各家 API Key（存在本机 userspace 里）
- Agent 等 AI 功能要和模型对话时，经它把请求发给供应商

## 配置说明

| 配项 | 在哪配 | 默认值 | 说明 |
|------|--------|--------|------|
| API Key | 设置页 → AI 供应商 | 空 | 各家供应商的密钥，保存在本机，不上传 |
| base_url | 供应商扩展自带配置 | 供应商默认 | 供应商接口地址，一般不用动 |
| 供应商列表 | `userspace/extensions/ai/providers/` | 随安装 | 往里装一个供应商扩展，设置页就多一家 |

## 常见使用方式

### 场景 1：第一次用 AI 功能

1. 打开设置页，找到 AI 供应商列表
2. 选一家供应商，把官网拿到的 API Key 粘贴进去并保存
3. 回到 AI 功能（如 Agent）直接使用

### 场景 2：换一家供应商

1. 确认新供应商已经出现在设置页列表里（没有就先装对应的供应商扩展）
2. 填入新供应商的 API Key
3. 在 AI 功能里切换到这家供应商

### 场景 3：AI 功能报错时自查

1. 确认这家供应商的 API Key 已填、没填错、没过期
2. 确认供应商的 base_url 没被改过
3. 确认填的模型名和供应商平台上显示的完全一致

## 常见坑与注意事项

- **API Key 配错**：表现为鉴权失败（401）。重新去供应商官网复制，粘贴时别带空格或换行
- **供应商 base_url 写错**：请求发去了错误地址，表现为一直超时或 404。恢复成供应商文档里的默认地址
- **模型名拼错**：报"模型不存在"。模型名区分大小写，以供应商平台显示为准
- API Key 只存在你自己机器上，但也不要把 userspace 目录整个发给别人
