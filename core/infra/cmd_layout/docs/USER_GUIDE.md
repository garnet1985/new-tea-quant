# 命令行布局 — 用户指南

**模块：** `infra.cmd_layout` · **版本：** `0.3.0`

**最低支持核心版本：** `>=0.5.0`

终端排版工具箱——打印标题、表格、条形图、图标，Windows 自动降级 ASCII。  
相关：[README.md](../README.md) · [API.md](../API.md) · [ARCHITECTURE.md](./ARCHITECTURE.md)

---

## 功能总览

- 你在终端里看到的整齐标题、对照表、进度条形图，都是它排出来的
- macOS / Linux 终端显示 emoji 图标，Windows 自动换成 ASCII 符号，不乱码
- 各模块的报告输出统一走它，所以不同命令的排版风格一致

## 配置说明

无用户可配项。排版规则内置，终端宽度自动适配。

## 常见使用方式

### 场景 1：看策略报告

1. 在终端跑策略相关命令
2. 输出里的标题区、参数对照表、收益条形图由本模块渲染
3. 直接阅读即可，无需任何设置

### 场景 2：在 Windows 上使用

1. 正常跑命令
2. 图标会自动从 emoji 降级成 ASCII 符号（比如用 `[ok]` 代替对勾）
3. 这是有意为之，不是显示故障

### 场景 3：输出显示异常时自查

1. 先把终端窗口拉宽一点，窄终端下表格可能换行错位
2. 确认终端编码是 UTF-8（macOS / Linux 默认就是）
3. 还有问题再向开发者反馈

## 常见坑与注意事项

- **Windows 上看到的图标和别人截图不一样**：正常的自动降级，不影响内容
- **表格在窄窗口里错位**：把终端拉宽再重跑，表格按字符宽度排版
- **用重定向把输出存成文件后样式丢失**：排版是给终端看的，存文件时建议只看文字内容
