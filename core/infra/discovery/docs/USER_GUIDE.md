# Discovery — 用户指南

**模块：** `infra.discovery` · **版本：** `0.2.1`

**最低支持核心版本：** `>=0.5.0`

自动发现扩展类——扫 userspace 下的 Provider、Handler、Strategy 插件。  
相关：[README.md](../README.md) · [API.md](../API.md) · [ARCHITECTURE.md](./ARCHITECTURE.md)

---

## 功能总览

- 你往 userspace 里装的扩展（数据源、AI 供应商、策略），启动时靠它找出来
- 扩展列表页能看到什么，取决于它扫到了什么
- 各模块不用自己写扫描逻辑，发现规则全系统统一

## 配置说明

无用户可配项。扫描的目录和规则由系统定好。

## 常见使用方式

### 场景 1：装了一个新扩展

1. 把扩展目录放到 userspace 下正确的位置（如数据源放 `userspace/extensions/data_source/`）
2. 重启应用
3. 在对应的列表页确认扩展出现了

### 场景 2：装了扩展但列表里看不到

1. 先确认目录位置放对没有（不同类扩展有不同目录）
2. 确认扩展文件是按模板写的，类继承了正确的基类
3. 重启后再看一次——发现发生在启动阶段

### 场景 3：自己写扩展

1. 照扩展模板的目录结构和命名来
2. 类名、基类按文档要求写，否则扫不到
3. 放好后重启验证

## 常见坑与注意事项

- **扩展放错目录**：扫描按固定目录来，放错位置等于没装
- **类没继承规定基类 / 命名不符约定**：文件在，但不会被认出来
- **改完扩展没重启**：发现是启动时扫的，热改不会自动生效
- 同名扩展可能互相遮盖，装之前先检查重名
