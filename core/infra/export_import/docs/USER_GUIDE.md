# Export / Import — 用户指南

**模块：** `infra.export_import` · **版本：** `0.2.0`

**最低支持核心版本：** `>=0.5.0`

打包和安装策略包 / 扩展包——打 zip 导出去，从 zip 装进来。  
相关：[README.md](../README.md) · [API.md](../API.md) · [ARCHITECTURE.md](./ARCHITECTURE.md)

---

## 功能总览

- 把本机的策略 / 扩展打成一个 zip 包，拷给别人或备份
- 拿到别人给的 zip 包，装进自己的 userspace
- 安装时发现同名文件，可以选：拒绝安装、跳过已有、或覆盖

## 配置说明

无用户可配项。冲突策略在每次安装时现场选择。

## 常见使用方式

### 场景 1：把策略导出给别人

1. 在策略管理界面选择导出
2. 得到一个 zip 文件
3. 把 zip 发给对方即可

### 场景 2：安装别人给的包

1. 拿到 zip 后，在安装入口选择该文件
2. 系统先做一遍预检，列出和本地冲突的文件
3. 选择冲突处理方式：拒绝（最保险）、跳过已有、或覆盖
4. 确认安装，完成后重启或刷新查看

### 场景 3：换电脑迁移

1. 旧机器上把策略包、扩展包逐个导出
2. zip 拷到新机器
3. 新机器上逐个安装，冲突策略选"拒绝"先试水

## 常见坑与注意事项

- **覆盖会盖掉本地改动**：本地改过的同名策略会被 zip 里的版本替换，覆盖前先备份
- **不是本系统打的包装不上**：zip 里带清单文件，手工压的 zip 缺清单会被拒
- **装完看不到**：扩展类内容要等重新扫描，重启应用再看
- 打包只装文件本身，不校验业务依赖——装完能不能用由对应业务模块说了算
