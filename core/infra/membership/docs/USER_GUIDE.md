# Membership — 用户指南

**模块：** `infra.membership` · **版本：** `0.1.0`

**最低支持核心版本：** `>=0.5.3`

官网会员凭证的本地存取——设置页写入，其他模块读取状态和凭证。  
相关：[README.md](../README.md) · [API.md](../API.md) · [ARCHITECTURE.md](./ARCHITECTURE.md)

---

## 功能总览

- 你在设置页粘贴的官网会员凭证，由它存到本机
- 会员相关功能（如外部数据服务）靠它判断"你是不是会员、凭证在不在"
- 凭证文件自动收紧权限，本机其他用户读不到

## 配置说明

无用户可配项。凭证固定存在 `userspace/system/membership/membership_token.txt`，由设置页或 CLI 写入。

## 常见使用方式

### 场景 1：开通会员功能

1. 登录官网会员中心，复制你的通用凭证（`ntq_` 开头的一串字符）
2. 任选其一写入本机：
   - 应用设置页：粘贴到会员凭证输入框并保存
   - 命令行：`python cli.py auth`（密码式提示，输入不回显；成功显示「token 设置成功」）
3. 保存成功后，会员功能立即可用

### 场景 2：更换或清除凭证

1. 换凭证：设置页覆盖，或再执行一次 `python cli.py auth`
2. 不用了：设置页点清除，或 `python cli.py auth --clear`
3. 仅查看是否已配置：`python cli.py auth --status`（不打印明文）

### 场景 3：会员功能提示"未配置凭证"

1. 先执行 `python cli.py auth --status` 或到设置页确认凭证已保存
2. 确认粘贴的是官网会员中心的那串，不是订单号或密码
3. 还不行就重新执行 `python cli.py auth` 粘贴一次

## 常见坑与注意事项

- **粘贴时带了空格 / 换行**：格式校验不过会提示「设置失败」并打印 Guide。凭证应是 `ntq_` + 48 位小写字符
- **输入不回显**：CLI 用密码式输入，终端不显示字符属正常
- **凭证文件权限太松被拒绝**：文件只许本用户读写（0600）。被手动改过权限就改回来，或删了重新保存
- **本模块不做在线验证**：凭证有没有过期要去官网看；过期了重新复制新的粘贴即可
- 凭证等同账号权限，不要把 `membership_token.txt` 发给别人
