# Progress（`infra.progress`）

记录当前这一次任务走到了第几步。安装、回测、扫描、归因、数据更新和标签计算都写这份进度，界面只读数字再自己算比例。

## 适用场景

- 一个长时间任务需要告诉界面做到哪一步
- 当前步骤里面还有可以计数的子步骤，例如文件、股票或页
- 安装、策略回测、数据源更新、标签计算需要同一套进度

## 模块依赖

- `infra.project_context`：定位 userspace 下的临时目录

## 设计初衷

- **要解决的问题：** 各模块各自写进度文件，界面要懂多套字段。
- **明确不做：** 不保存任务结果、错误原因或机会列表。那些仍由各业务模块自己记录。同一时间只保留当前这一次任务。

## 常见问题

**Q：百分比在哪里算？**  
A：不在本模块里算给界面用。界面用步骤和子步骤自己算。需要同一条式子时调用公开的比例方法，见 API。

**Q：两个任务同时跑会怎样？**  
A：后开始的任务覆盖当前进度。本模块不保留上一份任务的历史。
