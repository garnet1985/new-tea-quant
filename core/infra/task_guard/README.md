# Task Guard（`infra.task_guard`）

**模块：** `infra.task_guard` · **版本：** `0.2.0`

## 简介

长任务互斥锁。同一时刻只允许一个全局长任务（扫描、回测、更新数据等）占用资源。靠文件锁实现，跨进程可靠。**不是**任务队列或流水线调度——那个是将来的事。

## 适用场景

- 用户连续点击"跑一下扫描"，确保不会两个扫描同时跑
- 长任务崩溃后租约自然过期，不会一直锁住后面的任务

## 模块依赖

- `infra.project_context`：定位租约文件存储目录

## 设计初衷

- **要解决的问题：** 多进程环境下"同一时刻只允许一个重活"需要跨进程锁，不能每个模块自己写一遍文件锁。
- **明确不做：** 不做分布式锁（单机内有效）；不做任务重试或恢复。
