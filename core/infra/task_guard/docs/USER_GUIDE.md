# Task Guard — 用户指南

**版本：** `0.2.0`

长任务互斥锁——同一时刻只允许一个全局长任务占用资源。  
相关：[README.md](../README.md) · [API.md](../API.md) · [ARCHITECTURE.md](./ARCHITECTURE.md)

---

## 功能总览

- 跑扫描、回测、更新数据这类重活时，系统先抢一把锁，抢不到就排队或拒绝
- 跨进程有效：CLI 和 UI 同时启动也不会撞车
- 任务正常结束后锁自动释放；任务崩了，锁会自动过期，不会永久卡死

## 配置说明

无用户可配项。锁的过期时间和存放位置由系统统一管理。

## 常见使用方式

### 场景 1：避免重复启动长任务

1. 你点了一下"跑扫描"，任务开始
2. 不小心又点了一下，系统发现已经有任务在跑，会提示"已有任务进行中"
3. 等第一个跑完再发起新的即可

### 场景 2：查询系统忙闲

1. UI 上想看"现在能不能跑新任务"
2. 系统读一下当前锁的状态，告诉你忙还是闲
3. 闲就放心跑，忙就等一等

## 常见坑与注意事项

- **上次任务异常退出导致租约残留：** 任务崩溃时锁文件可能没主动删掉。系统有自动过期机制，等一会儿锁会自然失效；实在不行可以手动删掉 userspace 临时目录里的租约文件。
- **提示"任务在跑"但你明明没跑：** 多半是上次留下的残留锁，按上一条处理。
- **它不是任务队列：** 系统不会替你排队等，忙的时候发起新任务会被直接拒掉，需要自己稍后再试。
