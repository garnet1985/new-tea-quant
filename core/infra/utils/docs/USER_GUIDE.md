# Utils — 用户指南

**模块：** `infra.utils` · **版本：** `0.2.2`

**最低支持核心版本：** `>=0.5.0`

和业务无关的通用小工具——日期处理、CSV/zip IO、确定性随机。  
相关：[README.md](../README.md) · [API.md](../API.md) · [ARCHITECTURE.md](./ARCHITECTURE.md)

---

## 功能总览

- 给所有模块提供"日期怎么规范化、交易日怎么算"这种基础工具
- 提供 CSV 读写、zip 打包、Markdown 模板填充等通用 IO
- 装依赖时统一走镜像源（国内自动中科大，失败换清华/阿里云）

## 配置说明

| 配项 | 在哪配 | 默认值 | 说明 |
|------|--------|--------|------|
| `USE_CHINA_MIRROR` | 环境变量 | 自动按本机时区判断 | `1` 强制走国内镜像，`0` 强制走官方源 |

## 常见使用方式

### 场景 1：强制使用国内镜像装依赖

1. 默认会根据系统时区自动判断是不是国内
2. 判断不准时，设 `USE_CHINA_MIRROR=1` 强制走中科大 / npmmirror
3. 设 `USE_CHINA_MIRROR=0` 强制走官方 PyPI / npm

### 场景 2：写脚本时复用日期工具

1. 模块里要解析"2024-01-15"或"20240115"这种日期字符串
2. 直接调 Utils 的日期工具，不要自己再写一套
3. 算交易日偏移、生成确定性 UUID 同理

## 常见坑与注意事项

- **不要在业务模块里重复造轮子：** 想写 CSV、算日期，先看看 Utils 有没有，避免多处实现不一致。
- **它不是 pandas / numpy 的代理：** 大数据处理直接用 pandas / numpy，Utils 只做标准库级别的小工具。
- **镜像源只影响 pip / npm 装包：** 不影响 NTQ 自己读数据或访问行情接口。
