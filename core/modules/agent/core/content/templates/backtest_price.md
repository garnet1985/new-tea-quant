# 呈现模板 · backtest_price

**scenario：** `backtest_price` — 本轮读过价格层执行报告，且用户要总结 / 解读时，由 **present** 阶段套用。  
数字只能来自 work 结论（源自 `read_execution_report` 等）；禁止编造。

多层层报时仍可按 ## 枚举 / ## 价格 / ## 资金 分段，但**价格层内部**按下述骨架写（不要再套一层「## 价格」包住七块）。

## 输出骨架

### 策略回测报告：{display_name}

**{display_name}** 在 **{start}** 至 **{end}** 的回测周期内，共执行了 **{total_investments}** 笔交易，胜率 **{win_rate}%**，平均持仓 **{avg_duration_in_days}** 天。

核心理念：**{description}**（来自 `strategy_meta`；没有就省略）。

#### 收益成绩单

年化、交易日年化、均笔 ROI、累计盈利（摘要里比率多为小数，展示换成百分数）。  
跟一句体感（高 / 稳健 / 偏低 / 未盈利），勿保证实盘。

#### 交易拆解

盈利笔数 / 亏损笔数、胜率与盈亏比、持仓风格（按天数粗分超短 / 短 / 中短 / 中 / 长）。

#### 收益分布

用表格给出 `roi_p10 / p25 / p50 / p75 / p90`（若有）。  
解读中位数正负、`roi_iqr` 是集中还是两极分化。

#### 收益地形图（有 `roi_buckets` 才写）

占比较高的区间；是否堆在深亏区或高盈区。

#### 配置快照（有 `settings_snapshot` 才写）

初始资金、最大持仓、止盈 / 止损、最长持仓、佣金 / 印花税等。

#### 综合评语

1. **优势**（一个最亮特征）  
2. **风险**（一个最危险信号）  
3. **建议**（可执行的下一步）

结语必须提醒：**回测 ≠ 实盘**。

若用户同时要归因：价格报告之后另开 `## 归因`，不要把归因数字写进成绩单。
