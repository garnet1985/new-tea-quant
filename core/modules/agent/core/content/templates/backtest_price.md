# 呈现模板 · backtest_price

**scenario：** `backtest_price` — 本轮读过价格回测报告，且用户要总结 / 解读时，由 **present** 阶段套用。  
数字只能来自 work 结论（源自 `read_execution_report` 等）；禁止编造。

多层层报时仍可按 ## 机会盘点 / ## 价格回测 / ## 资金模拟 分段，但**价格回测内部**按下述骨架写（不要再套一层「## 价格回测」包住下列块）。

对外正文遵守：中文产品词、数字说成人话、不写配置字段名。

## 输出骨架

### 策略回测报告：{中文名称}

**{中文名称}** 在 **{开始日期}** 至 **{结束日期}** 期间，共做了 **{交易笔数}** 笔交易，胜率 **{胜率}%**，平均持仓约 **{平均天数}** 天。

策略在做什么：**{一句话说明}**（没有就省略）。

#### 一句话成绩

先用一两句说清赚亏体感（偏强 / 一般 / 偏弱 / 这段没赚到），再给关键数字：  
年化收益、按交易日折算的年化、平均每笔盈亏比例、累计盈亏。  
摘要里若是小数，展示换成百分数。勿保证实盘。

#### 交易大概什么样

盈利几笔 / 亏损几笔、胜率、盈亏比；按持仓天数粗分风格（超短 / 短 / 中短 / 中 / 长）。

#### 盈亏分布（有分位数才写）

用小表格给出偏低到偏高几档的单笔盈亏比例（如约一成、四分之一、一半、四分之三、九成位置的水平）。  
解读：中位数是赚是亏；中间一半交易是挤在一起，还是两极分化。

#### 盈亏落在哪几档（有分桶才写）

占比较高的盈亏区间；是堆在大亏区，还是堆在大赚区。

#### 当时用的主要设定（有快照才写）

用白话列：本金、最多同时持有几只、止盈 / 止损、最长持有、佣金 / 印花税等。不要写字段名。

#### 综合评语

1. **亮点**（一个最明显的好迹象）  
2. **风险**（一个最需要警惕的信号）  
3. **下一步**（一条可执行建议）

末尾一句提醒即可：**回测不是实盘。**

若用户同时要看止盈止损对照：价格报告之后另开 `## 止盈止损对照`，不要把对照数字写进成绩部分。
