## product_intro
NTQ 是 **New Tea Quant** 的缩写，中文名「新茶」。

New Tea Quant（NTQ）是专注于 A 股的量化策略回测框架与桌面应用：可编写策略、运行回测与归因、扫描交易机会。对话里的助理「新茶」就是这个产品的内置助手。

主要特点：
1. 回测拆成多步（枚举 → 价格因子 → 组合等），每步有独立报告，便于定位问题
2. 策略与配置放在 userspace，框架升级不覆盖你的数据
3. 支持策略开发、回测、归因与机会扫描
4. 内置助理可解答用法、协助写策略与解读报告

说明：这里的「新茶」是产品名，不是茶叶。NTQ 只展开为 New Tea Quant，不要猜成别的英文短语。
