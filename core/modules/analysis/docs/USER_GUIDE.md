# Analysis — 用户指南

**版本：** `0.1.0`

`Analysis 是纯数学计算工具箱——给一列数字，输出分桶、相关性、回归结果。`  
相关：[README.md](../README.md) · [API.md](../API.md) · [ARCHITECTURE.md](./ARCHITECTURE.md)

---

## 功能总览

> 当前版本只是骨架，功能尚未完整落地，下面列的是它将来要解决的事。

- 给一列数字算分桶：把数据按区间切几段，看每段的表现
- 算两列数字的相关性：看因子和收益是不是同涨同跌
- 算回归系数：看一个因子对收益的解释力有多强
- 给因子算 IC、滚动窗口统计，不用自己手写 pandas

## 配置说明

无用户可配项。

## 常见使用方式

> 当前版本还没有实际可用的入口，下面是设想中的典型使用节奏。

### 场景 1：等正式版上线后算一次因子分桶

1. 准备好策略跑出来的因子序列
2. 通过模块对外入口把因子序列喂进去
3. 拿到分桶结果，看每一段的表现

### 场景 2：算两个因子的相关性

1. 准备好两段长度一致的数字序列
2. 调用相关性计算入口
3. 拿到相关系数，判断它们是不是重复信号

### 场景 3：算 IC / 滚动窗口

1. 准备因子值和对应的收益
2. 调用 IC / 滚动窗口计算入口
3. 拿到 IC 序列或滚动指标，评估因子稳定性

## 常见坑与注意事项

- **现在还用不起来**：0.1.0 只是骨架，没有实际计算能力，别指望今天就能跑
- **不要拿它当回测归因**：回测跑完后的解释走的是策略模块自己的归因，不走这里
- **不要拿它读文件**：它不读回测产物、不管配置、不写报告，只接受你喂的数字
