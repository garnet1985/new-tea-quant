# 如何读回测报告

回测拆成几步，就是为了**分层诊断**。先看当前步右侧「回测报告」，标题旁的问号是指标说明。概念见 [回测四步](../wiki/strategy/backtest_pipeline.md)。

每步报告通常先有 **逐股样本** 表，下面是全局块。枚举和价格回测：点股票代码进入单股 K 线（机会点或买卖点）。投资模拟：有逐股盈亏表，不下钻 K 线。

## 枚举机会报告

问的是：**策略有没有找到机会？机会是否太稀、太扎堆、买不到？**

| 先看 | 含义 |
| --- | --- |
| 机会总数 / 完整度 | 样本够不够、有多少没走完目标 |
| 触发机会的股票占比、平均每股机会数、每股机会数分布图 | 是分散还是少数股票在贡献 |
| 平均间隔、持续天数、分散度 | 节奏密不密、好不好安排资金 |
| 涨停无法买入 / 跌停无法卖出 | 信号在规则下能不能成交 |
| 逐股表 | 对照总指标；点代码看 K 线上的机会标记 |

机会很少或全挤在几只股票上：先改 `has_opportunity` 或股票池，不要先调仓位。完整度低：回测窗口可能太短，或持仓周期相对结束日太长。

## 价格回测报告

问的是：**假设每笔都能按规则成交（还没有资金上限），单笔赚不赚？**

| 先看 | 含义 |
| --- | --- |
| 胜率、平均每笔 ROI、平均持有时长 | 信号质量；胜率要配盈亏幅度，避免小赢大亏 |
| 年化收益（自然日） | 线性折算，**偏乐观**，且短窗口会被放大；账户表现以投资模拟为准 |
| 总投资次数、覆盖股票、未完成持仓 | 样本和尾仓 |
| 成交跳过统计 | 涨跌停或状态规则跳过了多少笔 |
| 盈亏次数、平均盈利、ROI 分位图 / 分布 | 收益是否靠极端几笔；分布只含按 goal 退出的交易 |
| 逐股表（默认按 ROI 降序） | 点代码看买卖点 |

这里好看、投资模拟却很差：多半是仓位、现金、冲突或手续费的问题，不是信号本身。跳过很多：对照 `simulation.assumption` 和涨跌停规则。

## 投资模拟报告

问的是：**有限资金下账户能不能活、回撤能不能接受？**

| 先看 | 含义 |
| --- | --- |
| 资金结果总览：最终总资产、总收益率、资产与回撤曲线 | 最接近账户结果 |
| Calmar / 夏普 / Sortino | 收益相对回撤或波动 |
| 交易质量：次数、胜率、总盈亏、单笔平均盈亏 | 赚得稳不稳 |
| 仓位与资金利用率：平均持仓数、满仓天数、现金占比 | 长期满仓或长期闲置 |
| 风险结构：最大回撤、回撤持续、连续亏损 | 能不能执行纪律 |
| 股票集中度：前 5 贡献占比、收益离散 | 是不是靠几只股票 |
| 成交跳过 | 资金层假设下买不到、卖不出、或被参与率裁剪 |

总收益高但最大回撤很大：策略可能不适合你，不必再堆杠杆。前 5 贡献过高：枚举层已经很集中，或组合一直重仓同一批。

## 归因解读

跑完某步后，报告下方可能出现 **归因解读**（设置里打开分析，且安装了机器学习依赖）。它解释**这一次回测内部**哪些现场数字和收益一起变化，不是预测下次。

- 没有这块：设置 → 安装与维护补装机器学习组件；策略 `analysis.enabled`；再跑该步
- 「这次还无法归因」：样本太少，或钩子里没用 `ctx.capture(名称, 数值)` 记下会随行情变的数字

## 怎么对应到改哪

| 你看到的问题 | 先动哪 |
| --- | --- |
| 几乎没机会 / 太集中 | 枚举：钩子、股票池、`min_required_records` |
| 有机会但单笔 ROI 差、跳过多 | 价格层：goal、成交假设、复权口径（信号用前复权，ROI 用后复权） |
| 单笔还行，账户回撤大、经常满仓 | 投资模拟：初始资金、分配、手续费 |
| 程序化组合和你的直觉差很多 | 决策模拟：在已有枚举上自己选 |

版本对比：同一策略留多个 version，用顶栏恢复历史配置或对比报告，不要混着改很多处再一次下结论。
