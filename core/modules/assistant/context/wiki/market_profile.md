# 市场画像与交易日历

市场画像描述某个市场的制度：涨跌停、最小手数、结算周期。它不拉行情、不存数据，只提供规则。

策略在 `settings.py` 里用 `market_profile` 选用市场，回测成交和扫描会按这些规则检查。

## 内置市场

| 键 | 说明 |
| --- | --- |
| `china_a_stock` | 中国 A 股 |
| `hong_kong` | 港股 |
| `us_stock` | 美股 |
| `commodity_future` | 商品期货 |
| `forex` | 外汇 |
| `crypto` | 加密货币 |

## A 股规则

| 规则 | 板块 | 限制 |
| --- | --- | --- |
| 涨跌停 | 默认 | ±10% |
| 涨跌停 | 科创板（688） | ±20% |
| 涨跌停 | 创业板（300） | ±20% |
| 涨跌停 | 北交所（43/83/87/88/92） | ±30% |
| 涨跌停 | ST/\*ST | ±5% |
| 最小单位 | 默认 | 100 股 / 100 步 |
| 最小单位 | 科创板 | 200 股 / 1 步 |
| 最小单位 | 北交所 | 100 股 / 1 步 |
| 结算 | A 股 | T+1 |

板块按代码前缀匹配：`688*` 科创板，`300*` 创业板，`43/83/87/88/92*` 北交所。

无效价格时，涨跌停判断为「不在板上」，不会因此单独拦交易。

## 交易日历

日历在 `sys_trade_calendar`：每个自然日一行，`is_open` 标记是否交易。沪深 A 股统一用 `market=SSE`。

策略和标签里用 `ctx.data.calendar` 拿日历，不要自己查库。

最近已完成交易日的解析顺序：

1. `data.json` 里配置的 `as_of_latest_completed_trading_date`
2. 日历表
3. 实时抓取（新浪 → 东方财富）
4. K 线最大日期
5. 排除周末往回猜（最多 7 天）

回测时间轴默认按交易日构建，窗口受 `data.json` 的起止边界约束。
