# 第三步：组合模拟

## 什么是组合模拟

组合模拟是回测的第三步。它消费价格因子产出的单笔交易记录，加上资金管理、仓位分配、止盈止损纪律，模拟整个组合的表现——账户净值、回撤、夏普比率。

简单说：**如果真的按策略操作，你的账户整体表现如何？**

## 与前两步的区别

- 第一步：单只股票有没有机会

- 第二步：单笔交易赚不赚钱

- 第三步：组合层面——多只股票同时持仓时，资金怎么分配、风险怎么控制

## 输出

- 账户净值曲线（日频盯市）

- 逐笔成交记录

- 回撤数据

- 风险指标：Sharpe、Sortino、最大回撤

## 报告

组合报告回答这些问题：

- **账户总览**：初始资金、期末净值、总收益率

- **胜率盈亏**：组合层面的胜率和盈亏比

- **回撤**：最大回撤幅度、回撤持续时间

- **净值曲线**：每日账户价值变化

- **Sharpe / Sortino**：风险调整后收益

## 资金分配

由 `portfolio.allocation.mode` 控制：

| 模式              | 说明                 |
| --------------- | ------------------ |
| `equal_capital` | 等额资金分配（每只股票分配相同金额） |
| `equal_shares`  | 等股数分配              |
| `kelly`         | 凯利公式分配             |
| `custom`        | 自定义（需实现钩子）         |

其他资金约束：

- `max_portfolio_size`：最多同时持有几只

- `max_weight_per_stock`：单只最大仓位比例

- `lots_per_trade`：每次交易几手（1手=100股）

## 止盈止损纪律

组合阶段执行 `goal` 配置中的完整止盈止损体系：

- 分批止盈：涨 15% 不卖但抬止损、涨 30% 卖一半、涨 50% 卖剩余

- 保护性止损：成本价平仓

- 动态止损：从最高点回撤 15% 平仓

- 过期平仓：持仓 N 天后强制平仓

## 日频盯市

组合净值基于日频盯市（daily mark-to-market）：

- 每个交易日计算：现金 + 所有持仓的市值

- 持仓市值 = 未复权收盘价 × 未复权股数

- 当日平仓的持仓不计入当日盯市价值

- 缺失数据（如停牌）用最近可用收盘价

## 执行

组合模拟**不走 BacktestEngine**——不需要多进程，因为在组合层面已经是单线程的账户模拟。它在主进程内完成。

## 归因分析

组合跑完后，如果 `analysis.enabled = True`，自动生成归因报告：

- `facts`：给 UI 的数字（分桶、合成 tiers）

- `insights`：给 CLI 的叙事（headline、key\_findings、explains）

- 归因与该步同生共死——删了组合产物，归因也一起删
