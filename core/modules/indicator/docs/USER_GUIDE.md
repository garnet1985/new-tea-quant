# Indicator — 用户指南

**模块：** `modules.indicator` · **版本：** `0.2.0`

**最低支持核心版本：** `>=0.5.0`

`Indicator 是技术指标计算器——给 K 线，算 MA、RSI、MACD、KDJ 等。`
相关：[README.md](../README.md) · [API.md](../API.md) · [ARCHITECTURE.md](./ARCHITECTURE.md)

---

## 功能总览

- 给一串 K 线，算出常用技术指标：MA、EMA、RSI、MACD、布林带、ATR、KDJ（随机指标）、ADX、OBV 等
- 底层用的是社区维护的 `pandas-ta-classic`，公式和市面上多数看盘软件一致
- 既可以在策略配置里"声明"，也可以在分析脚本里"手动调"
- 多列指标（MACD、布林带）会返回一组序列，单列指标（MA、RSI）返回一条序列
- 内置批量计算：一次给一组指标配置，共享同一份 K 线，比逐个算快

## 配置说明

无用户可配项（模块本身）。但在**策略层**有一段和它强相关的配置：

| 配项 | 在哪配 | 默认值 | 说明 |
|------|--------|--------|------|
| `data.indicators` | 策略的 `settings.py` / `settings.yaml` | 无 | 声明本策略需要哪些指标（名称 + 参数 + 别名），回测时框架自动算好塞进每根 K 线 |

不写 `data.indicators` 的话，策略拿到的 K 线只有原始 OHLCV，不会附带指标列。

## 常见使用方式

### 场景 1：在策略 settings 里配指标

1. 打开策略的 settings 文件。
2. 在 `data.indicators` 下加一条：`name` 填指标名（如 `rsi`）、`params` 填参数（如 `length=14`）、可选 `alias` 给列起名。
3. 启动回测后，每根 K 线行里会自动多出一列（默认列名形如 `rsi14`），策略逻辑直接用。

### 场景 2：在分析脚本里手动算一次

1. 先从 `data_manager` 拿一段 K 线（带 OHLCV）。
2. 调 Indicator 的对应方法，例如要 20 日均线就调 MA、要 14 日 RSI 就调 RSI。
3. 拿到的是一个和 K 线等长的列表（前面 `length-1` 个位置会是空值，这是正常的）。

### 场景 3：看多列指标（MACD、布林带）

1. 调对应的 MACD / 布林带方法。
2. 返回是字典：MACD 给 `MACD` / `MACD_signal` / `MACD_hist` 三组序列；布林带给上 / 中 / 下轨。
3. 自己挑需要的序列用。

### 场景 4：策略里要一组指标，批量算

1. 把指标配置写成一个 dict（名称 → 参数）。
2. 用批量入口，一次传入 K 线和这份配置。
3. 返回每个指标的结果，共享了同一份 K 线预处理，比逐个算更快。

### 场景 5：看看本机环境支持哪些指标

1. 调"列出所有指标"的入口。
2. 拿到当前 `pandas-ta-classic` 暴露的全部指标名。
3. 想查某个指标的参数说明，用"查看指标帮助"入口。

## 常见坑与注意事项

- **前面几个值是空：** 指标都有"暖机长度"。20 日均线的前 19 个位置必然是空值，不是 bug。策略里要判空。
- **指标名拼错会静默返回 None：** 模块对失败的处理是记日志 + 返回 `None`，不抛异常。写完指标名先用"列出所有指标"确认拼写。
- **多列指标当单列用：** MACD、布林带返回的是字典，不是列表。直接拿去 `len()` 或下标会出错，要先取子序列。
- **K 线必须含 OHLC，部分指标还要 volume：** 只给 `close` 算不了 ATR、OBV 这类。从 `data_manager` 拿的 K 线默认字段是齐的；自己造数据时别漏。
- **改了指标参数但策略结果没变：** 检查是不是策略 settings 里 `data.indicators` 还在用旧参数；脚本里手动算的结果和策略 settings 算的是两条路径，互不影响。
