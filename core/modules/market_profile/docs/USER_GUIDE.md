# Market Profile — 用户指南

**模块：** `modules.market_profile` · **版本：** `0.2.1`

**最低支持核心版本：** `>=0.5.0`

`MarketProfile 提供各市场的交易规则——涨跌停幅度、整手单位、T+N 交割，策略判断能不能买入时查这里。`  
相关：[README.md](../README.md) · [API.md](../API.md) · [ARCHITECTURE.md](./ARCHITECTURE.md)

---

## 功能总览

- 查某只票当天是不是涨停/跌停了（按所属板块给幅度）
- 查某只票的最小申报单位（一手多少股、按几股递增）
- 查这个市场的交割周期（T+0、T+1、T+2 之类）
- 内置中国 A 股、港股、美股、Crypto、Forex、商品期货等市场，未来可扩展

## 配置说明

无用户可配项。各市场规则（涨跌停比例、整手数、T+N）都内置在模块里，用户态 `settings` 不读。如果你想加新市场或改规则，得改模块代码里的市场注册表，不是在配置里加一行。

## 常见使用方式

### 场景 1：策略里判断今天能不能追

1. 告诉模块你关心哪个市场（比如 A 股）。
2. 把股票代码喂进去。
3. 拿涨跌停幅度，结合当前价算上下限，判断现在是不是已经贴板了。

### 场景 2：算整手、凑申报数量

1. 选好市场。
2. 给股票代码和想买的目标数量。
3. 模块告诉你这只票的最小一手是多少股、按几股递增——主板整手、科创/北交所按步长、零股一次清完。

### 场景 3：确认交割周期

1. 选好市场。
2. 直接问"T 几"。
3. 策略里决定"今天买的哪天能卖"时用这个值。

### 场景 4：跨市场复用策略

1. 不要写死规则。
2. 启动时按标的市场切到对应 profile。
3. 后面所有规则判断都走模块，换市场不用改策略代码。

## 常见坑与注意事项

- **自己拼卖出数量容易错**：主板要整手、科创板/北交所按步长、不足一手的零股必须一次清完——直接让模块算，别自己写。
- **模块不查行情**：它只给规则，不告诉你"现在多少钱"。当前价、昨日收盘这些数据要策略自己从数据模块拿。
- **不同板块涨跌幅不一样**：A 股主板 10%、创业板/科创板 20%、北交所 30%、ST 5%——别用一个固定比例一刀切，按代码走匹配规则。
- **规则是只读的**：运行中改不了，也不需要改。要加新市场，走模块代码层的扩展。
