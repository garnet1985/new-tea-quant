# NtqExternal（`modules.ntq_external`）

**模块：** `modules.ntq_external` · **版本：** `0.1.0`

## 简介

NTQ 本地和官网之间的唯一对接点。拿官网页面地址、查会员资料、走官网的 AI 通道、提交应用内反馈——凡是要和远端服务器交互的，都从这里走。

## 适用场景

- 其他模块要展示免责声明、注册入口等官网页面链接
- 需要读用户的会员档位、猫粮余额等资料
- Agent 调 AI 时走官网会员通道（模型密钥留在官网，本机只有通用凭证）
- 用户在应用内提交评分或意见反馈

## 模块依赖

- `infra.membership`：读取会员通用凭证
- `infra.project_context`：路径与配置
- `infra.trace`：登记官网接收端

## 设计初衷

- **要解决的问题：** 所有对外交互集中一处，URL 不分散拼、凭证不回传明文、断网和未登录分开处理。
- **明确不做：** 不保存模型密钥、不做登录注册（跳转官网）、不做支付。
