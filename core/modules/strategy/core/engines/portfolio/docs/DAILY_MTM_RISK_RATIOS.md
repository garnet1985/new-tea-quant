# 资金层：按日盯市的夏普 / Sortino

**状态：** v1 已落地（无风险 / Sortino 目标仍为 0；SHIBOR 另开）。  
**位置：** `simulate` 成交已定之后、`ReportManager.finalize` 写报告之前；不改事件驱动模拟，不走 BE。

同一条日频盯市曲线同时供给：夏普、Sortino、最大回撤、回撤持续、Calmar、权益/回撤图、**最终总资产**、**总收益率**。胜率 / 已实现盈亏仍走成交。

---

## 1. 问题

业界年化夏普默认：每个交易日把组合按市价盯市 → 日收益（减无风险，本仓库第一版仍为 0）→ 均值 / 样本标准差 → ×√252。Sortino 同理，分母换成相对 0 的下行波动（上涨段贡献 0，分母用全部段数）。

### 1.1 模拟怎么记净值（成交回放，不变）

`PortfolioSimulator` 按买卖事件走账户，换日时 `_append_equity` 调 `account.equity({})`。空行情字典下，持仓按 `average_cost` 计价。曲线只在成交换日记点，不是每个开市日。这笔成本记账只服务成交回放，**不进报告**。

### 1.2 不要用事件点去乘 √252

曾试用事件段收益 ×√252。公式常见，但把稀疏成交日当成交易日是**口径错误**。该实现已删除。样本再多也不会收敛到日频盯市夏普。

Calmar 仍是「区间总收益 / 最大回撤」，不是年化 Calmar；只把所用曲线换成日频盯市。

## 2. 已排除的路

| 方案 | 结论 |
|------|------|
| 枚举给每笔机会算夏普，资金层当选择器去取 | 否。夏普属于**整份账户**，不是单笔机会。 |
| 枚举「完整路径」拼账户净值 | 否。落盘只有触发/买入/卖出等稀疏点。 |
| `price_change_rate_delta` 单独当输入 | 否。那是单股相对昨收，不是账户收益。 |
| 模拟改成按交易日 `Timeline.drive` / 再走 BE jobs | 否。成交逻辑不依赖每日市值。 |
| 只改年化乘数、不盯市 | 否。仍看不见持仓内波动。 |
| 未复权股数 × 交易所 raw 收盘 | 否。10 送 10 会假腰斩净值。 |
| 把 hfq 收盘当现金价去乘买入股数 | 否。hfq 不是可成交价。 |

SHIBOR 作无风险合理，第一版继续 rf = 0。接 SHIBOR 单独立项（建议隔夜，折成日利率）。不要用 LPR。

## 3. 约定实现：成交后盯市，再算风险比

资金模拟保持事件驱动（选仓、现金、上限、成交）。  
盯市是报告步骤：用**实际成交**（`sim.trades`），不是枚举全表。

```text
PortfolioSimulator.run（不变）
  → 盯市：成交 + 开市日 + 持仓期 hfq 收盘
  → 日净值序列（替换模拟器事件点）
  → EquityCurves / 夏普 / Sortino / 回撤 / Calmar
  → ReportManager 落盘
```

成交结果、钩子、测试不因盯市而变。库读失败只影响风险块（夏普 / Sortino 显示 —，保留成本曲线并打日志），不要把模拟搞脏。旧报告不要回填错误口径；需重新跑资金步。

### 3.1 挂载点

`ReportManager.finalize` 内、写 `equity_curve` / overall 之前。`capital_metrics` 保持无 IO。

模拟器内部的 `equity({})` 成本记账先不动。有账户止损、按市值加减仓等**会改变成交**的规则时，再把盯市推进模拟循环。

## 4. 算法

输入：本次 `PortfolioSimResult.trades`、回测 `start_date`/`end_date`、`initial_capital`。  
输出：每个开市日的现金、净值、持仓数。

### 4.1 计价：hfq ROI 反推同股等价

仓位冻结买入股数。盯市与现金盈亏同一把尺（因子口径的分红再投资，不接 Tushare `dividend` 双账户）：

```text
ROI_d     = (hfq_close_d − entry_hfq) / entry_hfq
mark_px   = entry_raw × (1 + ROI_d)
value     = buy_shares × mark_px
```

`entry_hfq` 是**成交**后复权价（`EnumResult.entry_price_hfq` → 买入事件 / `Trade`），不是买入日收盘。买入当天含 fill→收盘。注释和 UI 写明：假设红利再投资同一标的。

卖出日这条路径与已进账现金对齐：

```text
profit = shares × entry_raw × hfq_ROI
```

（`Trade.hfq_cash_profit` / `equivalent_exit_value`）

K 线读 `bar["hfq"]["close"]`（或 `raw.close × adj_factor`）。不要用 qfq 收盘，也不要用 raw 收盘去乘冻结股数。

### 4.2 回放持股与现金（不读行情）

按成交日期排序。每个开市日结束时：

- 现金：仅在买卖日因成交和费用变化；其余日沿用
- 各股股数：仅在该股买卖日变化
- 开市日列表：交易日历一次查询（回测期，A 股用 SSE 即可）

回测结束仍持仓的，窗口接到 `end_date`（最后一个开市日）。期末净值**含未实现**。

### 4.3 买卖当天

先按成交改现金和股数，再用**当日 hfq 收盘**给**收盘后仍持有**的仓位标价。已清仓的股票当天不再计入市值（盈亏已进现金）。不要用全日涨跌幅去代替成交价。

### 4.4 非交易日（有持仓、无买卖）

```text
净值_d = 现金_d + Σ_i (买入股数_i × entry_raw_i × (1 + ROI_{i,d}))
```

停牌或缺 bar：该股沿用其最近一次已有 hfq 收盘。不要为填洞再拉更长历史。从未有过 bar：按成本（ROI = 0）标。

空仓日：净值 = 现金，不读股票 K 线。

### 4.5 日收益与比率

对盯市后的 `equity[d]` 计算日收益后再年化（仅当曲线已按开市日盯市；成本/事件点不算夏普）：

```text
夏普 = mean(r − rf) / sample_std(r − rf) × √252
Sortino = mean(r − MAR) / sqrt(mean(min(r − MAR, 0)²)) × √252
```

v1：`rf = 0`，`MAR = 0`。段数不足 2 或波动≈0 时不展示（`—`）。下行波动用**全部**交易日（上涨日平方贡献 0）。相邻点必须是交易日，×√252 才成立。

最大回撤、回撤持续天数在这条全日序列上算（抽稀前）。写给 UI 的曲线仍可抽到约 80 点。BFF 权益图读全量 `equity_curve.json`。

### 4.6 不纳入第一版

- 现金利息
- 盘中高低 / 用开盘价盯市
- 无风险利率（SHIBOR）
- 年化 Calmar
- 价格层 / 枚举层夏普
- 为旧 `equity_curve.json` 做离线补算

## 5. K 线怎么取（内存与次数）

不要 `load_batch(所有成交过的股票, 整个回测区间)`。

**需要行情的区间 = 该股首次买入日 → 最后卖出日或 `end_date`（含当天）。** 清仓之后不再取。查询次数 ≈ **曾持有过的股票只数** + **1 次交易日历**。

实现约束：

- 只取 `date + hfq.close`，不要整根 OHLC 留在内存
- 按股或小批量（建议 10～20 只），用完丢弃 bar
- 峰值内存 ≈ 日净值数组 + 当前这一批收盘

## 6. IO 粗估（`rsi_v1_baseline` 仿真 3）

样本：500 只池、约 3 年、最多 10 槽 → 盯市约 23 次 K 线量级，墙钟大约 **0.3～0.5s**。满仓 10 槽 × 10 年大约 **1～3 秒**。不要为这件事上 BE。
