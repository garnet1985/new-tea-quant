# 归因要答什么

**状态：** 产品目标锁定（2026-10-03）。**主文档：** [ATTRIBUTION_SWEEP.md](./ATTRIBUTION_SWEEP.md)（参数扫描 + 共用身份 + 分层曲线）。战役身份 [ATTRIBUTION_CAMPAIGN.md](./ATTRIBUTION_CAMPAIGN.md) §0；配置 [ATTRIBUTION_INPUTS.md](./ATTRIBUTION_INPUTS.md)；展示 [ATTRIBUTION_PRESENT.md](./ATTRIBUTION_PRESENT.md)；枚举 / 价格 / 组合见各层文。

**一句话：** 回答「改这个数字，结果变好还是变坏、该设多少」——默认单因素多档扫描与曲线；不是「因子贡献了百分之几」，也不是以 SHAP 为主角。

---

## 1. 用户故事

- 阈值 / 过滤有没有帮我得到更好结果？该松还是紧？  
- 止损止盈带对没有（太紧 / 太小）？  
- 资金槽位与分配对不对、有没有买到该买的？  

三问归一：**改参数 → 看结果 → 找更好数字（并看曲线是否稳健）。**

---

## 2. 方法与三层

| 概念 | 口径 |
|------|------|
| 扫描点身份 | **一套共用** version（主号 + 副本），见 CAMPAIGN §0 |
| 默认扫描 | 单因素多档（其余固定当前 settings） |
| 可选 | `joint_sweep` 小矩阵；全因子大矩阵一般不做 |
| CLI | `sea` / `spa` / `soa` = 懒补深度 + 本层纵轴曲线，不另起展格 |
| 枚举 | 机会数量 / 分布 / 纸面出场 |
| 价格 | 去噪等权边；出场结构；SHAP 仅附录 |
| 组合 | 收益·回撤·利用率；买到 vs 漏掉 |
| 滚动 | `sw` 验证较优点是否换窗仍站得住 |

详细目标、报告结构、差距表：[ATTRIBUTION_SWEEP.md](./ATTRIBUTION_SWEEP.md)。

---

## 3. 原则

- 「如果改 X」必须对应扫描点里真有的档位；没有就只给方向。  
- 文案带条件：「在其余设置保持当前时…」；较优标明样本内。  
- 禁止：幸存者上 SHAP 解释「贡献了多少机会」；无格子的反事实百分比。  
- 决策模拟（`sd`）不进参数扫描战役。

---

## 4. 明确先不做

- 以贡献度分解为主答案  
- 默认全因子大矩阵 / ANOVA 全家桶  
- 系统代算 MFE「错过盈利空间」  
- 把归因做成第四层回测  
- 执行诊断（人 vs 机器）
