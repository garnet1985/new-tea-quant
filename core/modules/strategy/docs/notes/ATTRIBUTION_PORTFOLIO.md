# 组合层归因口径

**状态：** 口径已锁定（2026-10-02）。实现必须先对本文。总方向见 [ATTRIBUTION.md](./ATTRIBUTION.md)；枚举 [ATTRIBUTION_ENUM.md](./ATTRIBUTION_ENUM.md)；价格 [ATTRIBUTION_PRICE.md](./ATTRIBUTION_PRICE.md)。战役格子仍以 [ATTRIBUTION_CAMPAIGN.md](./ATTRIBUTION_CAMPAIGN.md) 为准。

**一句话：** 组合层回答「钱有没有买到该买的机会，以及怎么把钱用得更好」。价格层是等权交易账；这里才有资金、槽位、仓位规则。

---

## 1. 用户为什么要跑这一层

价格层是去噪后的等权机会账，同股两段可以时间重叠。组合层按 `portfolio.allocation` 真正下单：等权资金 / 槽位上限 / 单票权重 / 现金不够就跳过；**账户里已有该股则不再买**（rsi_v3：`equal_capital`、最多 10 槽、单票 30%、`skip_trade_when_insufficient`）。

这次 v32：价格做完约 124 笔，账户成交 48 笔；平均持仓 3.5、峰值 10（槽位顶满）；利用率均 25%、峰 93%；满仓天数约 16%。平时现金闲着，机会扎堆的日子槽位满了买不进。这就是「钱用没用在刀刃上」。

---

## 2. 用户想了解什么

1. **该买的买到了没有。** 价格账本里有、账户没买的那些，质量比买到的更好还是更差。漏掉的更好 → 资金/槽位把好机会挤掉了；漏掉的更差 → 约束碰巧在过滤。
2. **买到的仓位合不合理。** 等权是否把钱摊在差机会上；赚的钱是否来自少数重仓；回撤是不是同一天槽位里的票一起跌。
3. **什么样的机会更值得投。** 把价格账本里的机会分组（现场 RSI/PE、时期、出场类型），看哪一组等权更赚，再看账户实际买的是不是那一组。价格层回答「哪类交易有边」；组合层回答「钱有没有流向那一类」。
4. **怎么改分配才更赚。** 诊断只陈述已发生的（漏掉的比买到的均收益高多少、满槽日漏了多少）。「如果槽位改成 20 / 改成 Kelly / 按 RSI 加权」必须 `portfolio.inputs` 真跑过对照格，没有格子只给方向：槽位顶满、好机会在满槽日，考虑加槽或排序；不编「年化会高 2%」。

决策模拟（`sd`，人怎么选）不进本文。

---

## 3. 可以归因

单次 version：

- 折损：价格完成笔数 vs 组合成交笔数；平均 / 峰值持仓 vs `max_portfolio_size`；利用率均 / 峰；满仓天数比例
- 买到 vs 漏掉：用价格账本当全集，组合成交当子集。比两组的均 ROI、胜率、现场因子、触发日历。漏掉的定义：价格层有、组合没有买（槽位满、现金不足、权重上限、**同股已持仓**）
- 分组：按现场因子分位、按年/季、按出场类型，看「等权更赚的组」和「账户实际买的组」是否同一批
- 仓位结果：单票最大权重、是否近似等权、前 5 只盈利集中度（现有 `top5_profit_concentration_pct`）、回撤段同时亏损的持仓数

有对照格时：对照的是上述折损和「买到 vs 漏掉」质量差。动 `max_portfolio_size` / `mode` / `max_weight_per_stock` 才叫改进资金；不要把账户收益差再讲成一遍 PE 贡献。

---

## 4. 需要对照格

- 加槽、改等权 / Kelly、放宽单票上限：必须 `attribution.py` 里真有 `portfolio` 格子
- 按因子排序再填槽：现有分配模式若没有这一项，不要在归因里假装回测过；只能根据「漏掉组更好」建议去改分配规则再跑

---

## 5. 明确不做

- 再做一遍枚举的分散 / 门贡献、价格层的等权账本诊断
- 无对照格时编「如果按 RSI 加权年化 +2%」
- 用 SHAP 解释资金利用率
- 把组合收益说成单笔等权边（那是价格层）
- `sd` 人机差别

---

## 6. 数据从哪读

- 组合 `overall_report`：利用率、持仓峰值、top5、回撤
- 组合成交：`portfolio/trades.json` 或投资明细
- 价格账本当「本来能做的全集」，做买到 / 漏掉集合差
- 现场因子仍来自枚举 `signal_snapshot` / capture，跟到对应 `investment_id`

---

## 7. 和上面两层的边界

- 枚举：全部机会纸面路径（含重叠）
- 价格：去噪后等权机会账（段与段可并行、不受总资金限制）
- 组合：这本账里实际买了哪些、买了多大、漏了什么
