# 归因如何展示

**状态：** 口径已锁定（2026-10-02）。各层问什么见 [ATTRIBUTION.md](./ATTRIBUTION.md)；枚举 / 价格 / 组合口径另文。战役格子仍以 [ATTRIBUTION_CAMPAIGN.md](./ATTRIBUTION_CAMPAIGN.md) 为准。

**一句话：** 哪一层归因你跑（`sea` / `spa` / `soa`），就出那一层的战役报告。报告三个区块：事实、结论、建议。不要等三层都跑完再出一份混叙事。

---

## 1. 为什么一层一份

调机会分布时，账户利用率和满槽漏单是噪音。分别跑 `sea` / `spa` / `soa`；层内指标跟回测层走，不要求其它层已经归因过（但该层回测主 version 必须先有）。

- 枚举可单独归因（`sea`，须先 `se`）
- 价格对照合并偏需要枚举/价格产物（须先 `sp`）
- 组合买到/漏掉需要价格账本（须先 `so`）

战役仍是一次任务一个文件夹：对照的是**同一套层内指标**的差分。不是一个 `sa` 跑满三层。

机器学习不挡调试：枚举默认不做 XGB；价格层（`spa`）可附单笔 XGB+SHAP。

---

## 2. 一份报告三块

同一文件、三个作者，不要拆成用户要找的两份。

| 区块 | 写什么 | 不写什么 |
|------|--------|----------|
| **事实** | 统计（及可选 ML）数字：数量、分散、出场、胜率、买到/漏掉 | 解释、下一步、反事实百分比 |
| **结论** | 这些数字说明什么（偏少、较集中、止损偏多、门本格看不出） | 「如果改 X 年化 +2%」 |
| **建议** | 下一步改哪一类设置；有 overlays 就引用格子上的同一套指标 | 只跑枚举时建议资金；无对照格时编百分比 |

只跑枚举：建议里不准写槽位 / 利用率。结论可以点名「要看门贡献请 overlays」。
