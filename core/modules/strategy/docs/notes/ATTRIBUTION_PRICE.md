# 价格层归因口径

**状态：** 口径已锁定（2026-10-02，同日按「用户从这一层带走什么」改过一版）。实现必须先对本文。总方向见 [ATTRIBUTION.md](./ATTRIBUTION.md)；枚举层见 [ATTRIBUTION_ENUM.md](./ATTRIBUTION_ENUM.md)。战役格子仍以 [ATTRIBUTION_CAMPAIGN.md](./ATTRIBUTION_CAMPAIGN.md) 为准。

**一句话：** 价格层把枚举机会收成一本可执行的等权交易账，回答「这本账赚不赚钱、结不结实」。不是随机抽样，是按时间锁仓的确定性抽取。枚举回答找没找到；组合回答钱够不够用。

---

## 1. 用户为什么要跑这一层

枚举把每笔探测到的机会都按 `goal` 独立走完，**含时间重叠**。同一只股票上两段纸面路径可以叠在一起，那不是真实能同时持有的交易。

价格层回放：持仓期间后来的机会进不来，再去掉涨跌停 / 停牌买不进。得到的是一份 **可执行的等权交易账本**。

用户要带走的不是「又一份机会诊断」，而是：

1. **交易有没有边。** 胜率、平均 ROI、盈亏比、ROI 分布。这是「策略赚不赚钱」的第一份答案，还没被仓位上限和现金稀释。枚举纸面盈亏含重叠，不能当这个答案。
2. **锁仓 / 可交易性有没有把边改坏。** 枚举 125 笔、价格 124 笔，差可以忽略。机会很密、大量后到的触发被锁仓挤掉时，才要看被挤掉的是不是系统性更差。
3. **给组合层当对照。** 价格有边、账户没有 → 去查资金；价格没边、账户也不好 → 先改想法，不是先改仓位。

rsi_v3 这次每股约 1.2 次机会，v21 / v22 / v32 枚举与价格笔数几乎相同。那只说明锁仓没改样本，**不**说明这一层没意义：用户仍应看到这份等权账本的胜率和 ROI 分布。

---

## 2. 用户想了解什么

他们面对的是一本已经抽好的交易账，想知道的是这本账**值不值得信**，不是再找一遍机会。

1. **整体有没有边。** 胜率、均收益、盈亏比。还没被资金稀释的「策略赚不赚钱」。
2. **是不是靠少数几笔撑的。** 去掉赚得最多的几笔 / 几只票，平均 ROI 还是不是正的。枚举问的是机会堆不堆；这里问的是**利润**堆不堆。rsi_v3 的 p10 已是 -20%、中位 +20%，要能说清左尾是不是少数止损、右尾是不是普遍止盈。
3. **钱从哪种出场来。** 止盈 / 止损 / 到期各自贡献了多少总利润（笔数 × 均收益）。这和枚举「止损对哪类票不合理」不是同一问：这里是账本盈亏分解。
4. **边会不会随时间垮。** 按年 / 季切这本账，是不是某一年在赚钱。单次 version 就能切；跨窗口稳不稳仍走 `sw`。
5. **抽样有没有偏。** 锁仓挤掉的、涨跌停跳过的，是不是系统性更差。不是随机抽样，是先到先锁；无差就一句。
6. **做成的这些交易里，现场因子还分得出赚亏吗。** 附录。标的是这本账，不是全部枚举机会。不要讲成「RSI 贡献了多少机会」。

有 overlays 时再加：旋钮一动，这本账的边怎么变（胜率升了均收益掉了，还是笔数多了质量垮了）。

枚举已经回答、这里不要展开：机会散不散、门有没有干活、止盈止损对哪类票哪段时期不合理（分档 / 按月切开）。价格出场结构相对枚举明显变了，只写对照。

---

## 3. 可以归因

单次 version 就能做：

- 账本：完成笔数、胜率、平均 ROI、盈亏比、ROI 分位 / 分桶（price `overall_report` 已有，必须收）
- 利润是否头部化：前 N 笔 / 前 N 只票占总利润比例；去掉它们之后均收益还正不正
- 出场对总利润的贡献：各 `exit_reason` 的笔数、均收益、利润合计（不是枚举那套按票/按月「合不合理」）
- 按年 / 季的胜率与均收益
- 相对枚举的抽样差：锁仓挤掉、涨停、跌停、停牌；无差写一句，有差再比被挤掉的盈亏

有 overlays 时对照的是上述**账本边和结实程度**，不要把价格胜率再讲成一遍 PE 贡献。

现场因子分桶 / SHAP：附录，且只用这本账的成交。

---

## 4. 明确不做

- 再做一遍机会分散、门的有/无、止盈止损按票/按月诊断（那是枚举的）
- 把价格层 SHAP 当这一层的主答案（现场因子分桶若做，是附录，且标的是这份交易账本）
- 把价格层 ROI 说成账户收益
- 因为笔数和枚举一样，就整章省略（用户会以为没有「交易赚不赚钱」这张答卷）
