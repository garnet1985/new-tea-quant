# 价格层归因口径

**状态：** 回放口径已改（2026-10-02）：去噪并行，不再锁仓。归因展示尚未按本文加厚。引擎决策见 [PRICE_REPLAY.md](./PRICE_REPLAY.md)。总方向 [ATTRIBUTION.md](./ATTRIBUTION.md)；枚举 [ATTRIBUTION_ENUM.md](./ATTRIBUTION_ENUM.md)。战役格子仍以 [ATTRIBUTION_CAMPAIGN.md](./ATTRIBUTION_CAMPAIGN.md) 为准。

**一句话：** 价格层是枚举去噪后的等权机会账：近的并成一段、远的各走各的（可重叠）。回答这本账赚不赚钱、结不结实。枚举回答找没找到；组合回答钱够不够用、同股能不能再买。

---

## 1. 用户为什么要跑这一层

枚举把每笔探测到的机会都按 `goal` 独立走完，**含时间重叠、含同一段信号连打的枪**。密集成片会让「普遍盈利」和因子权重被同一段行情拉歪。

价格层：按 `opportunity_merge_gap` / `is_new_opportunity` 把近的丢掉、留下每段的主机会，**段与段可以并行**。再去掉涨跌停 / 停牌买不进。得到的是一份 **去噪后的等权机会账**，还没被槽位和现金稀释。

用户要带走的：

1. **去噪后的机会有没有边。** 胜率、平均 ROI、盈亏比、ROI 分布。枚举纸面盈亏含密集成片，不能当这个答案。
2. **合并 / 可交易性有没有把边改坏。** 丢掉的是过近的续命中，还是涨跌停。被并掉的若系统性更差，要写出来。
3. **给组合层当对照。** 价格有边、账户没有 → 去查资金（含同股已持仓跳过）；价格没边、账户也不好 → 先改想法，不是先改仓位。

---

## 2. 用户想了解什么

1. **整体有没有边。** 胜率、均收益、盈亏比。还没被资金稀释的「策略赚不赚钱」。
2. **是不是靠少数几笔撑的。** 去掉赚得最多的几笔 / 几只票，平均 ROI 还是不是正的。枚举问机会堆不堆；这里问**利润**堆不堆。
3. **钱从哪种出场来。** 止盈 / 止损 / 到期各自贡献了多少总利润。
4. **边会不会随时间垮。** 按年 / 季切；跨窗口仍走 `sw`。
5. **去噪有没有偏。** 并掉的续命中、涨停跳过的，是不是系统性更差。无差就一句。
6. **做成的这些交易里，现场因子还分得出赚亏吗。** 附录。标的是这本去噪账，不是全部枚举机会。不要讲成「RSI 贡献了多少机会」（门贡献在枚举 overlays）。

有 overlays 时再加：旋钮一动，这本账的边怎么变。

枚举已经回答、这里不要展开：机会散不散、门有没有干活、止盈止损对哪类票哪段时期不合理。价格出场结构相对枚举明显变了，只写对照。

## 3. 可以归因

单次 version 就能做：

- 账本：完成笔数、胜率、平均 ROI、盈亏比、ROI 分位 / 分桶（price `overall_report` 已有，必须收）
- 利润是否头部化：前 N 笔 / 前 N 只票占总利润比例；去掉它们之后均收益还正不正
- 出场对总利润的贡献：各 `exit_reason` 的笔数、均收益、利润合计
- 按年 / 季的胜率与均收益
- 相对枚举：笔数差（合并 + 涨跌停 / 停牌）；无差写一句，有差再比被丢掉的盈亏

有 overlays 时对照的是上述**账本边和结实程度**，不要把价格胜率再讲成一遍 PE 贡献。

现场因子分桶 / SHAP：附录，且只用这本账的成交。
