# 归因目标：参数扫描（2026-10-03）

**状态：** 产品目标已锁定。战役身份 / 懒执行仍以 [ATTRIBUTION_CAMPAIGN.md](./ATTRIBUTION_CAMPAIGN.md) §0 为准；配置细节见 [ATTRIBUTION_INPUTS.md](./ATTRIBUTION_INPUTS.md)。层内指标见 ENUM / PRICE / PORTFOLIO 文。

**一句话：** 用户问的是「改这个数字，结果变好还是变坏、该设多少」；主方法是**单因素多档参数扫描 + 曲线 + 敏感度排序**；底层**共用一套扫描点身份**，三层 CLI 懒补产物、各画各的结果曲线。

---

## 1. 用户故事（三问归一）

本质只有一句：**我改一下这个参数，结果会变好还是变坏？我该把数字调成多少？**

展开为调试场景：

| 场景 | 用户在想 |
|------|----------|
| 阈值 / 过滤 | 门槛有没有帮我得到更好结果？松一点还是紧一点？ |
| 止损 / 止盈 | 是不是太紧频繁止损？是不是太小截断利润？ |
| 资金分配 | 槽位 / 单票上限 / 分配方式该多大？钱有没有买到该买的？ |

不追求：「因子 A 贡献了 30%」（交互下无唯一分解）。  
不把 SHAP 当主角（仅价格层附录：入场现场量与后续盈亏的相关性）。

---

## 2. 方法（默认 / 可选）

| 方式 | 何时用 | 成本 |
|------|--------|------|
| **单因素扫描（默认）** | 每轴多档，其余固定为当前 settings | 轴数 × 档位数 |
| **联合扫描（可选）** | 用户声明 2（偶 3）轴一起扫 → 热力图 | 如 5×5=25 |
| **全因子大矩阵** | 一般不做 | 指数爆炸 |

单因素匹配用户渐进调参；联合扫描只在怀疑交互或单因素后再精修时用。

文案模板（须带条件句）：

> 在其余设置保持当前时，止损从 −30%→−5%，〔本层主指标〕峰值在 −15%；−20%～−10% 较平（稳健区间）。样本内较优，换窗口请用 `sw` 验证。

禁止默认写成「去掉 A 贡献 −X%」。

## 4. 三层报告各自回答什么

同一套扫描点；每层纵轴与诊断不同。

### 4.1 枚举（`sea`）

- **问：** 阈值/过滤如何改变机会数量与分布？纸面止盈止损结构是否极端？  
- **主推轴：** `core.*`；`goal.*`（纸面出场）。  
- **曲线纵轴：** 机会数、覆盖/触发率、`top_bucket_ratio`、止损率/止盈率等。  
- **范围句：** 纸面结局、含重叠；不是价格去噪账，不是组合资金。

### 4.2 价格（`spa`）

- **问：** 去噪后等权投一笔能不能赚、赚够不够？止盈止损松紧从出场结构与边上看是否离谱？  
- **主推轴：** `goal.*`、`core.*`；可选 `opportunity_merge_gap`。  
- **曲线纵轴：** 胜率、均 ROI、总盈亏、盈亏比、ROI 中位。  
- **辅助：** 出场原因分布；利润是否头部化。  
- **附录：** capture / SHAP（相关性，非因果）。  
- **不做：** 系统代算 MFE「错过多少空间」。

### 4.3 组合（`soa`）

- **问：** 槽位/权重/分配是否让钱买到该买的？收益与回撤怎样随仓位参数变？  
- **主推轴：** `portfolio.allocation.*`。想法轴若在共用点上已有组合产物，可作终局曲线，但结论勿讲成「PE 贡献」。  
- **曲线纵轴：** 收益、回撤、利用率等。  
- **辅助：** 买到 vs 漏掉；仓位/回撤结构。

### 4.4 层间衔接（报告头）

每层报告开头一句上游规模，例如：价格基于枚举机会经去噪后的代表笔数；组合基于价格完成笔数中实际买入笔数。链到上一层报告（展示层，不另起战役）。

## 5. 每层报告固定结构（目标 UX）

1. **敏感度排名**（按该层主指标随档位的起伏）  
2. **每轴一条曲线**（档位 → 主指标；标当前 settings 落点、样本内较优、稳健区间）  
3. **层内诊断块**（枚举：分散；价格：出场分布；组合：漏买/回撤）  
4. **建议**（可执行的调档方向；无格子不编百分比）  
5. **可选：** `joint_sweep` 热力图  
6. **价格附录：** 因子分析（可选 / 可关）

## 6. 配置目标形态

```python
attribution = {
    "inputs": {
        "rsi_oversold_threshold": {"values": [20, 25, 30, 35]},
        "max_pe_percentile": {"values": [None, 20, 30]},
        "stop_loss": {"values": [-0.10, -0.15, -0.20, -0.25]},  # 单段可简写
        "take_profit": {"values": [0.10, 0.15, 0.20, 0.25]},
        "max_portfolio_size": {"values": [4, 6, 8, 10, 15]},
    },
    # 默认单因素；勿对全部轴 cross
    "joint_sweep": [
        ["stop_loss", "take_profit"],  # 可选：仅这两轴笛卡尔，其余固定
    ],
    "rolling": {"windows": [...]},
}
```

- 默认展格 = oaat 多档（不是全轴 `cross: true`）。  
- `joint_sweep` = 额外任务：指定轴子集的小矩阵；与「全轴 cross」不同。  
- 过渡：分块 `enumerate.inputs` 等仍合并为同一套身份。
