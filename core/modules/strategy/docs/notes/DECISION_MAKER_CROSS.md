## 1. 为什么要重跑枚举

决策时钟**不现场算止盈止损**。卖出来自枚举产物里冻好的出场事件（`PortfolioPipeline.build_events`）。公共窗口或成交规则一改，各策略工作台里的旧 version 就是错的。

因此不拼 RSI v3 + BB v4。选的是**当前策略**（没有 version 概念），在合并后的 settings 下重跑枚举，写进 `_decision/{session}/`。

---

## 2. 合并公式

```text
枚举用 settings = 策略自己的 settings  ← 被 _decision/settings.py 覆盖（仅白名单键）
```

- `_decision` **不是策略**。不要 `strategy.py`，不要出现在策略列表。下划线前缀本来就不走发现规则。
- 覆盖写进 **session 快照**，不要改各策略磁盘上的 `settings.py`。
- 各策略保留：`strategy.py`、`core`、`goal`（含自定义 `is_take_profit` / `is_stop_loss`）、`data` / 抽样 / 股票池、`simulation.execution.mode`（entity / slice）。
- 时钟只依赖各策略这份枚举，**不跑**各策略的投资模拟。

### 公共 settings 白名单（建议）

只允许「一本账必须同一套」的键，多写了就拒绝或忽略：

| 放公共 settings | 不放（策略个性） |
|-----------------|------------------|
| 时间窗口（`simulation.execution` 的 start/end；空 = 全体走系统默认） | `core` / `goal` / `data` / `sampling` |
| 成交假设、手续费、`risk_control` | `execution.mode` |
| 本金、`max_portfolio_size`、建议手数用的 allocation | `meta` / `scanner` / `analysis` |
| （可选不写）`market_profile`：选择页保证所选策略市场一致即可 | |

本金和组合上限必须在公共 settings：对局只有一份现金。不要读「第一只策略的 10 万」。

## 3. 产品规则

1. **选策略，不选 version。** 改了某策略入场代码或个性 settings，开新 session 再枚举。
2. **股票池跟策略。** A 只声明创业板就只扫创业板，B 全市场就全市场。机会列表是并集。
3. **市场必须一致。** 选择页拒绝混市。
4. **同一标的同一天两只策略都报是正常的。** 两张卡都亮，用户选**按哪只策略执行**（买那一张）。持仓后同一标的再来另一只策略，只能看不能买（沿用「已持有不能再开仓」）。v1 不做分策略加仓。
5. **lot 键 = 策略 + 股票 + investment_id。** 合并枚举时必须带策略名，否则各策略的 `"1"` 会撞车。
6. **枚举齐了才能开时钟。** 一只失败只重跑那只；不要先开局再补枚举。
7. **同一份枚举可开多局时钟**，避免每局重跑。

### 枚举复用（不挡开工）

最差：每个成员都 run 一遍枚举。能跳过的条件（实现时再细化）：

- 合并后的执行指纹与已有产物一致
- 已有日期窗盖住公共窗口（可再裁一段）

工作台里那份旧枚举通常对不上（窗口已被覆盖）。可复用的多半是 `_decision` 里上一次 session。

## 4. 磁盘（建议）

```text
userspace/strategies/_decision/          # 不是策略包
  settings.py                            # 公共覆盖（白名单）
  {session}/
    meta.json                            # 成员列表、市场、冻结的公共 settings、各策略合并指纹
    enum/{strategy_key}/                 # 该成员在合并 settings 下的枚举产物
    decision/
      meta.json                          # 各局索引、last_session_id
      {dm_id}/                           # 与单策略局同结构
```

目录名用 `_decision`（单数）。本地若已有 `_decisions` 草稿，开工时改成这个名字。

报告：整局净值 / 交易可复用单策略报告；另加按**实际买入那张卡**归属的策略贡献（笔数、占用、已实现盈亏、胜率）。「报了但没买」单独算覆盖率，不要算进贡献。不要把各策略自己的 portfolio 净值加总当对照（本金会重复）。

---

## 5. 流程

```text
写公共 settings → 选市场一致的策略（≥2）
  → 冻结 session 快照
  → 逐个枚举（可缓存）到 enum/{strategy}/
  → 全部成功后开局：合并事件流、一本资金、一张日历
  → 走完 finalize（与单策略局同结构）
```

时钟行为对齐单策略：停在有机会或仓位变化的日子；纪律卖出来自该 lot 所属策略的枚举出场。
