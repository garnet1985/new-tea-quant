# 滚动对照（2026-10-08）

**状态：** 产品口径已锁定。入口是 `engines/rolling`，报告挂在主 version 的 `rolling/report.json`。窗口号是 `{主号}-roll{n}`。换版本后，没有这份报告就是未执行。

**一句话：** 资金回测跑完之后，用户另配若干区间，用当前同一套设置再跑，报告只给出每段相对这次回测的差值。过拟合、时效、稳不稳定由用户自己看。

---

## 1. 它不是什么

- 不是归因。归因回答「在这次回测的区间里，改一个设置，结果变好还是变坏」。Rolling 不再放在 `attribution.py`，不和参数战役同一张表，也不靠归因才能跑。
- 不是制定策略的第五步，也不是决策者的前一步或后一步。前三步加决策者是同一段区间、同一份 version 上的一次模拟；决策者只是把这次资金回测用人再走一遍。Rolling 不读决策者的选择，也不挡住决策者。
- 系统不下「过拟合」「有时效」「稳定」这种结论，也不分析大环境。区间像不像，由配窗口的人负责。

## 2. 何时用

资金回测已经完成，用户也已经按归因把设置调好。Rolling 是这次回测之外的对照：当前设置冻住，只换区间。

使用上排在决策者前面更顺（先看机器结果换一段还像不像，再决定要不要亲手走这段）。入口独立，不插入四步步进器。

## 3. 配置

窗口写在策略目录的 `rolling.py`，不进 `settings.py`，也不进 `attribution.py`。起止日即可。重叠、包含、短于或长于原回测都可以，框架不限制、不改正。完全相同的窗口可以拒绝。

没有配窗口就不跑。原回测的起止日就是对照基准，不需要用户再写一遍。

## 4. 报告

基准是当前这次回测的主 version，不是第一段窗口，也不是「哪段收益最高」。

表的第一行是这次回测本身。后面每一段旁边是和它的差值。三层各看这几列：

| 层 | 对照列 |
|---|---|
| 枚举 | 机会数、触发股票数、时间分散（`cv`） |
| 价格 | 胜率、平均收益率、前 5 笔利润占比 |
| 资金 | 最大回撤、夏普、Sortino、Calmar |

账户总收益留在资金层当原文，不参与差值。时间分散的文字结论并排留下，也不做差值。

每一行标出这段多长、和原回测重叠多少。重叠会把两边的数往一起拉，读者需要看见这件事，才能判断差值是新区间带来的，还是同一段又算了一遍。

页面和终端都不出现结论句。

窗口模拟写在 `{主号}-roll1`、`{主号}-roll2`，不进版本列表，不占用归因副本 `{主号}-attr{n}`，也不推进主号。报告在 `results/simulations/{主号}/rolling/report.json`。没有 `rolling.py`，或枚举、价格、资金三步没有都完成，就不跑。删这个主号时，窗口目录和这份报告一起删。

## 5. 工作台

命令行仍是 `sr`。投资组合执行面板有「滚动测试」，默认不可点。枚举、价格、资金都完成，并且策略目录的 `rolling.py` 能读出窗口，按钮才可点。设置指纹对不上这个 version 时，界面把它当成未执行。

进度按每个窗口的枚举、价格、资金各更新一次，不跟进单层内部的细进度。跑完后报告区多一个「滚动对照」页，内容和终端同一份 `rolling/report.json`。
