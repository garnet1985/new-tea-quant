# appBrand

NTQ 顶栏品牌标。

```js
import AppBrand from 'ui/ntq/appBrand';

<AppBrand version={<AppVersion />} />
```

| 参数 | 默认 | 说明 |
|------|------|------|
| `to` | `/welcome` | 首页路径 |
| `name` | `New Tea Quant` | 文案 |
| `logoSrc` | `/logo.png` | 徽标 |
| `version` | `null` | 版本槽 |
| `linkComponent` | `RouterLink` | 链接组件 |
