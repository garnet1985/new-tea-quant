# 页面文档：`decision.html` / `decision-play.html`

## 这个页面是干什么的？
两层入口：
- **决策模拟**：制定策略第四步（单策略）。回放当前策略的 `portfolio`：人只改「选谁」和「买多少股」。
- **决策者**：主导航入口，现在仍可进单策略对局；将来扩展为多策略超级决策模拟。

## 页面目的与用户价值
- 单策略走工作台第四步，不必离开制定策略页。
- 主导航入口保留「开始 / 继续 / 管理」。
- 在「停在有事的那天」做抉择，体会选择的分量。
- 推进前先看账单（含本日不买），避免把顶栏按钮直接当成 CLI `next`。

## 页面功能描述

### 制定策略第四步
- 依赖枚举机会 + 投资模拟都完成（价格回测不是前置）。
- 左栏：持仓状态为主（含持仓市值）；约束条件与状态统计默认收起。当前局数标在执行面板标题后。
- 执行面板与交易日历同一栏；推进钮仍在日历旁。
- 有进行中的局则续上；否则新开。

### 入口 `decision.html`
- 三个入口卡：开始新决策、继续、管理。
- **继续**不猜测：0 局不可用；1 局直接进；≥2 局先列出。
- **管理**：列出进行中 / 已完成；进入、只读回看、删除（原型本地）。

### 对局 `decision-play.html`
- 顶栏日历 HUD：只显示事件日（机会或仓位变化），不可点选跳转；现金 + 推进。
- 左：策略+模拟（只读）→ 资金仓位 → 持仓。
- 右上：当天 event（只读出场，先于新机会）。
- 右下：新机会（编号、买入价、该标的 as-of 胜率 / ROI、建议股数、投入股数与约等于金额）。建议股数含「股」；投满组合上限后未下单行的投资钮与输入禁用。
- 点机会行打开 `info` 抽屉：策略 vs 标的 as-of，K 线截至当前日 \(D\)；持仓点开时标注买入日。
- 推进：有新机会时先确认账单（空选择 = 本日不买）；仅仓位变化的日子直接推进到下一事件日。
- 已完成局只读：不能改股数、不能推进。

## 页面假设与 Placeholder
- 全部为前端 mock，不接 BFF / 不写盘。
- 样例策略 `rsi_v1` version 3；机会列表只示意当日子集。
- 日历格子不是自然日，空日不占格。
- 过程中不展示净值曲线、未来卖出日、机器当天选了谁。
