# 页面文档：`decision.html` / `decision-play.html`

## 这个页面是干什么的？
入口：
- **决策模拟**：制定策略第四步（单策略）。回放当前策略的枚举：人只改「选谁」和「买多少股」。
- **跨策略决策模拟**：推迟到 0.5.1，口径见 `core/modules/strategy/docs/notes/DECISION_MAKER_CROSS.md`。

## 页面目的与用户价值
- 单策略走工作台第四步，不必离开制定策略页。
- 在「停在有事的那天」做抉择，体会选择的分量。
- 推进前先看账单（含本日不买），避免把顶栏按钮直接当成 CLI `next`。

## 页面功能描述

### 制定策略第四步
- 依赖枚举机会 + 投资模拟都完成（价格回测不是前置）。
- 左栏：持仓状态为主（含持仓市值）；约束条件与状态统计默认收起。当前局数标在执行面板标题后。
- 执行面板标题右侧：继续 / 管理 / 新开一局。继续只选进行中的局；管理可进入、回看、删除。
- 有上次打开的局则续该局时钟（含已完成）；没有存档才新开。
- 当前仿真 version 至少走完一局，顶部第四步变绿；切到进行中的局也不熄灭。
- 执行面板与交易日历同一栏；推进钮仍在日历旁。走完后推进换成「查看报告」，报告出现在事件 / 机会那一栏（左栏持仓与执行面板仍在），形状与投资模拟相同，默认可对比投资模拟，也可对比本策略其他已完成局。

### 入口 `decision.html`

全局入口已从主导航拿掉（跨策略推迟到 0.5.1）。本文件仅作历史原型；产品入口是制定策略第四步。

### 对局 `decision-play.html`
- 顶栏日历 HUD：不可点选跳转；现金 + 推进。事件回溯弹出更大的月历表：格子上方「发现 x 个机会」，其下为「买入/卖出名称 股数，花费」。
- 左：策略+模拟（只读）→ 资金仓位 → 持仓。
- 右上：当天 event（只读出场，先于新机会）。
- 右下：新机会（编号、买入价、该标的 as-of 胜率 / ROI、建议股数、投入股数与约等于金额）。建议股数含「股」；投资格常显股数输入，金额占右侧；投满组合上限后未下单行禁用。
- 点机会行打开 `info` 抽屉：策略 vs 标的 as-of，K 线截至当前日 \(D\)；持仓点开时标注买入日。
- 推进：有新机会时先确认账单（空选择 = 本日不买）；「返回查看」关掉账单并保留已选股数；仅仓位变化的日子直接推进到下一事件日。
- 已完成局只读：不能改股数、不能推进。

## 页面假设与 Placeholder
- 全部为前端 mock，不接 BFF / 不写盘。
- 样例策略 `rsi_v1` version 3；机会列表只示意当日子集。
- 日历格子不是自然日，空日不占格。
- 过程中不展示净值曲线、未来卖出日、机器当天选了谁。
