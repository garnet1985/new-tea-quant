# Calendar Sliced 模式基准 Tag 场景

用途：
  - 性能测试的标准 baseline（calendar_sliced 模式）
  - 验证时间切片批量处理的吞吐量和 IO 特性

特点：
  - 横截面计算（需要当日所有实体的数据）
  - 排序 + 百分位计算（中等复杂度）
  - 典型的因子预处理场景

为什么选择市值百分位？
  1. **代表性**: 大量因子策略都需要横截面标准化/排名
  2. **数据依赖**: 必须看到全市场数据才能计算 → 测试切片 IO
  3. **计算量适中**: 排序 O(N log N) + 百分位映射，不会太轻也不会太重
  4. **输出稳定**: 每个实体每日都有一个值，便于统计

与 Timeline 模式对比：
  - Sliced: 时间切片批量（适合横截面排名、全市场统计、因子值）
  - Timeline: 逐实体遍历（适合事件驱动、状态变化检测）
